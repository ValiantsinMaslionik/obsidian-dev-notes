## Value Stream

Value Stream is a representation of an end-to-end collection of value-adding activities that create an overall result for a customer, stakeholder, or end user.

A value stream is the set of actions that take place to add value to a customer from the initial request through realization of value by the customer. The value stream begins with the initial concept, moves through various stages of development and on through delivery and support. A value stream always begins and ends with a customer. Value streams are artifacts within business architecture that allow a business to specify the value proposition derived by an external (e.g., customer) or internal stakeholder from an organization. A value stream depicts the stakeholders initiating and involved in the value stream, the stages that create specific value items, and the value proposition derived from the value stream. The value stream is depicted as an end-to-end collection of value-adding activities that create an overall result for a customer, stakeholder, or end-user.

## Conway's Law

> Any organization the designs a system (defined broadly) will produce a design whose structure isa copy of the organization's communication structure.

The lay is not just about communication, it is about organizational communication and how it will be applied in the architecture. Organizational capabilities should be mapped to system capabilities, which need to be aligned with each other. Moreover, an organizational change can indicate a system change, and a system optimization can indicate a change in the organization as well. For example, automating a manual process means that an employee will not be needed any more or that his/her task will be given to a supervisor.
